Developing SettleTown

Basics

SettleTown uses Bevy, an open-source game engine. Bevy utilizes a model called ECS, which stands for Entity Component System. It is a development paradigm often associated with game development. It has a number of basic concepts associated with it, but the three main concepts are described in the title:

Entities

Entities are data structures that store zero or more Components. They are general-purpose game-world objects. They must have a unique id, but other than that, they can be effectively empty structs. For example, a PlayerCharacter entity may exist, representing the player character for the game.

struct PlayerCharacter(u64);

Components

Components are basic Rust structs (typically, they can also be enums or zero-sized types) that implement the Component trait. They are data structures used to store data for an Entity. In abstract terms, they are definitions that an entity contains a particular aspect. For example, the PlayerCharacter entity, from above may have a Position component, allowing it to exist somewhere in the world space.

#[derive(Component)]
struct WorldPosition {
    x: f32,
    y: f32,
}

Systems

A System is an operation that acts on all entities having a given component. For example, with the above PlayerCharacter and WorldPosition structs, a Movement system may exist that queries the entities with a particular position and updates that position.

fn update_position_system(mut query: Query<&mut WorldPosition>) {
    for position in &query {
        position.x = position.x + 1;
        position.y = position.y + 1;
    }
}
